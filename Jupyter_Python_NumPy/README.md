# Versiones Jupyter en Python y NumPy

Esta carpeta contiene una traduccion conceptual de los notebooks Pluto a Jupyter.
La interactividad de Pluto no siempre tiene un equivalente exacto; por eso se usa `ipywidgets` cuando esta disponible y funciones de Python que tambien pueden ejecutarse manualmente.

Dependencias principales:

- Python 3
- NumPy
- Matplotlib
- ipywidgets, opcional para controles interactivos

Las versiones priorizan reproducir las ideas matematicas y visuales de los notebooks originales, no una conversion automatica celda por celda.
